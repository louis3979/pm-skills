# Maintenance — Index

Dated reports from `/review`, the weekly maintenance sweep. See `log/` for the history.

A memory system that's never swept rots quietly: stale facts get treated as current, hypotheses sit unresolved forever, stakeholders get forgotten. The sweep is what keeps this system trustworthy — budget ~20 minutes for it on a regular cadence (default: weekly; see `rules/INDEX.md` and `CLAUDE.md § Operating preferences` if a different cadence was set).

Each report in `log/` covers the same six checks: stale knowledge, stale evidence, hypothesis hygiene, stakeholder cadence + strategy tension, knowledge compression, archival sweep.
