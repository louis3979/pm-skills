# 1:1 Prep

## Purpose

Turn scattered context about one direct report into a focused prep note, so the manager shows continuity across sessions instead of improvising.

## Context

Use the previous 1:1 note for this person, if one exists, plus any recent status updates mentioning their work.

## Instructions

1. Review prior commitments first — list action items/promises from both manager and report from the last session, marked done/not done. This always comes first since it demonstrates consistency.
2. Summarize recent work signals: what deserves specific recognition (don't skip concrete praise) and what needs coaching — grounded in actual input, never inferred when data is missing.
3. Prepare topics to proactively raise, not just wait on: upcoming org changes affecting them, feedback that shouldn't wait for a formal review cycle.
4. Prepare 1-2 career-development questions periodically — open questions tied to something they've said before, not generic ones.
5. Prepare an open listening question instead of one-way reporting, e.g. "what's been most frustrating this week that nobody's asked about yet."
6. Never fabricate content when input is missing — say "no history — first session, or data unavailable" instead of inventing a commitment that never happened.

```markdown
# 1:1 Prep — <person name>, <date>

## Prior commitments tracked
| Commitment | Owner | Status |
|---|---|---|
| [e.g. "Finish onboarding flow redesign"] | [Manager/Report] | [Done / Not done / In progress] |

## Recognition & coaching
- Recognition: [specific, not generic]
- Coaching: [specific gap or pattern, with an example]

## Topics to proactively raise
- [An org change, or feedback that shouldn't wait for a review cycle]

## Career-development questions
- [One open question tied to something they've said before]

## Open listening questions
- [e.g. "What's been most frustrating this week that nobody's asked about yet?"]

## New commitments after this session
<fill in after the meeting>
```

If a pattern shows up across several people's 1:1s, roll it into a team-level health rollup or the weekly digest rather than treating it as one person's issue.

## Notes

- A commitment marked "not done" two sessions running is a pattern worth naming directly in the 1:1, not just re-listing silently.
- No career topic in the last 3 sessions? Proactively schedule one now.
- If no prior notes exist and this isn't clearly a first session, say history is missing rather than guessing what was discussed.
