# Board Update

## Purpose

Compress a period's product results into a concise, numbers-first update that survives a skeptical board audience — a different, higher bar than an internal update.

## Context

Pull this period's metric outputs and the committed targets (OKRs/roadmap) to compare against.

## Instructions

1. Open with a one-sentence Headline: good/bad/mixed vs. plan, stated directly — the board may read only this line.
2. Present core numbers as a table: metric, this period, last period, target, % of target. Never substitute a qualitative adjective for a number.
3. Explain the Why behind the numbers, especially if a target was missed — the real cause, not a vague external excuse if a more specific one exists.
4. State 2-3 product highlights for the period (a launch, a big insight, a strategic shift) — 1-2 sentences each, no process narration.
5. State risks/challenges plainly — a board loses trust faster from discovering a hidden problem than from hearing bad news directly.
6. Separate out the Ask if the board needs to decide/approve something: exactly what's needed, the deadline, and a recommended option.
7. Prepare 3-5 Anticipated Questions the board is likely to ask based on the numbers/risks above, with answers already drafted.

```markdown
# Board Update — <period>, <year>

## Headline
<one sentence>

## Core Numbers
| Metric | This period | Last period | Target | % of target |
|---|---|---|---|---|

## Why (especially if target missed)
<direct explanation>

## Product Highlights
- ...

## Risks / Challenges
- ...

## Ask (if any)
<what's needed, deadline, recommendation — e.g. "Approve $X for Y by [date]; recommend approving because Z">

## Anticipated Questions & Answers
**Q: [the hardest question the numbers/risks above invite]**
A: [direct answer, no hedging]
```

If the Ask involves a major strategic bet, back it with a fuller strategy memo. If a metric miss needs root-cause digging first, run that analysis before finalizing the Why section.

## Notes

- Every metric needs a comparison point (prior period or target) — a bare number is incomplete.
- A missed target always gets an explicit Why, even when the true cause is uncomfortable (execution miss, wrong bet) — don't default to external-cause explanations without evidence.
- If this period's numbers aren't finalized yet, say so and use the latest confirmed figures with an "as of" date rather than presenting an estimate as final.
